API

The watcher's JSON API, for your own control, script or key.

The watcher listens on 127.0.0.1:<port> (8790 by default). The CLI, the Stream Deck keys and the React example all use this API.

Endpoints

RequestBodyAnswer
GET /state200 and the state.
POST /switch{"branch": "..."}202 and the state once the switch has started; follow /state's switch. It looks at origin first, so a branch pushed a moment ago is found. Otherwise {"error": "..."}: 409 for uncommitted changes or a switch already running, 404 for a branch that isn't listed.
POST /pull{}The checkout's branch: 202 with switch.pull true, or 202 with "Already up to date" in switch.notes. 409 when not on a branch, 404 when the branch isn't on GitHub.
POST /refresh{}Looks at git and GitHub now; 200 and the state when done.
POST /walk{"name": "…"}Runs a walkthrough in a browser on this machine; 202, then follow the state's walk. 409 while one or a switch is running.

POSTs need Content-Type: application/json.

curl -s http://127.0.0.1:8790/state
curl -s -X POST -H 'Content-Type: application/json' -d '{"branch":"claude/fix-login"}' http://127.0.0.1:8790/switch

  "project": "bmx",
  "base": "main",
  "current": { "branch": "claude/fix-login", "sha": "…" },
  "dirty": false,
  "upstream": { "sha": "…", "behind": 2 },
  "branches": [
    { "branch": "main", "short": "main", "sha": "…", "date": "…" },
    { "branch": "claude/fix-login", "short": "fix-login", "sha": "…", "date": "…",
      "merged": true, "pr": { "number": 42, "title": "Fix login", "draft": false, "updatedAt": "…" } }
  ],
  "prs": true,
  "webhook": "connected",
  "webhookError": null,
  "refreshedAt": "…",
  "error": null,
  "switch": { "target": "claude/fix-login", "pull": false, "phase": "running",
              "step": "mix deps.get", "error": null, "notes": [], "at": "…" },
  "walkthroughs": [{ "name": "fix-login", "path": "walkthroughs/fix-login.exs", "new": true }],
  "walk": { "name": "fix-login", "phase": "running", "step": "Log in with the new form", "error": null, "at": "…" }
}
FieldWhat it is
currentThe checkout's branch and commit.
dirtyTracked files have uncommitted changes (a switch would be refused).
upstreamThe checkout's branch on origin, and how many commits the checkout is behind it; null when the branch isn't on origin.
branchesThe list, base first. merged is there when every commit is in the base; pr when it has an open pull request.
prsWhether the list comes from open PRs (a GitHub token was found).
webhook"off" (no channel set), "connecting" or "connected".
switchThe last switch or pull: phase is "running", "done" or "failed", step the label of the step it's on.
walkthroughsThe checkout's walkthroughs; new when the branch added or changed it since it left the base.
walkThe last walkthrough run from the page or API: phase is "running", "passed" or "failed", step its caption.

Who can call it

  • It answers this machine only: the Host header must be localhost or 127.0.0.1, which also stops DNS rebinding. The same goes for the pages, including the config editor.
  • Browsers only from allowed origins: the watcher's own, the servers' localhost and 127.0.0.1 ports, and the config's origins. A page elsewhere can't make the browser send a JSON POST here without a CORS preflight, which only those origins pass.
  • Webhook deliveries are only a hint to look again; the watcher never acts on their contents.
