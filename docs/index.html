clawswap

Runs a project's dev servers in one zellij or tmux session, and switches the checkout to another branch from a Stream Deck key, a web page or the command line.

clawswap is made for reviewing the branches Claude (or anyone) pushes. A switch stops your servers, checks the branch out, runs only what the change needs (mix deps.get, migrations, npm install...) and starts the servers again. The branch list shows the open pull requests, newest commit first, with each one's merge status, and lights up when the branch you're on has new commits on GitHub.

InstallElixir, zellij and clawswap, and the clawswap command. Useclawswap up, the session and every command. Configureclawswap.exs or clawswap.yml, by hand or from the page's editor. SwitchingWhat a switch and a pull do, step by step. Branch pageThe watcher's page, merge marks, and embedding it in your app. APIThe JSON API, to build your own control. Stream DeckBranch and pull keys through OpenDeck, or from the page over WebHID.

How it fits together

GitHub ──webhook── smee.io ──SSE── clawswap watch (its own pane) ──zellij/tmux── server panes
                                        ▲ 127.0.0.1:8790
              OpenDeck "clawswap branch" keys, the Hologram page at /, clawswap switch
  • The session. clawswap up opens a zellij or tmux session with a pane for each of your servers, one for the watcher and one for each extra pane you configure.
  • The watcher (clawswap watch, in the session's clawswap pane) is an OTP app. It keeps the branch list up to date from git and GitHub, runs switches, and serves a page and a JSON API on 127.0.0.1:8790.
  • The webhook. GitHub posts branch, push and pull-request events to a smee.io channel; the watcher follows the channel and looks again when one arrives. Without it, it looks every 15 minutes and whenever you press a key.
  • The controls. Stream Deck keys (an OpenDeck plugin, or the page itself over WebHID), the watcher's Hologram page (on its own or in an iframe in your app), your own control built on the API, and the CLI all drive the same watcher.

Quick start

Once clawswap is installed and clawswap is on your PATH:

cd <path-to-your-project>
clawswap init     # writes a starter clawswap.exs from what it finds
clawswap smee     # optional: a webhook channel, so new branches show up straight away
clawswap up       # opens the session; the page is at http://127.0.0.1:8790

Then pick a branch on the page, press a key, or run clawswap switch <branch>.

All Elixir

clawswap is written in Elixir. The watcher is an OTP application, its page is a Hologram page served by Phoenix, and the OpenDeck plugin is an Elixir script. It started as devtools/bmx-dev in the bmx project; the servers and steps that were written into it are now a config file in each repo.
