Stream Deck keys (OpenDeck)

Branch and pull keys on a Stream Deck, through the OpenDeck plugin.

Install the plugin

<path-to-clawswap>/opendeck/install.sh

It can be run from anywhere. It copies the plugin into OpenDeck's plugins folder (~/.config/opendeck/plugins, or the Flatpak's under ~/.var/app/me.amankhanna.opendeck). It's a copy, since OpenDeck doesn't reliably follow a symlink there, so run it again after updating clawswap.

  1. Make sure Elixir 1.18 or newer is on the PATH OpenDeck sees. OpenDeck starts the plugin as bin/plugin, which runs plugin.exs with elixir. A version manager that only sets Elixir up in your shell won't do.
  2. Quit OpenDeck fully (tray > Quit) and start it again; it only starts plugins when it launches.
  3. Drag clawswap branch (category clawswap) onto keys, and clawswap pull onto one.

The keys need the project's watcher running (clawswap up).

clawswap branch

Each key either shows the next branch or a branch you name (set in the key's settings).

  • Keys on "next branch" share the list in deck order, row by row. The first shows the base branch, the rest the newest open pull requests.
  • A key shows its branch's PR number and title.
  • Pressing it switches to that branch: the servers stop, the branch is checked out, the steps it needs run and the servers start again.

A bar on the key shows its state:

  • Green: the checkout's branch.
  • Blue: the checkout's branch has new commits on GitHub; press it to pull them.
  • Amber: a switch in progress, with its step.
  • Red: a failed switch.

clawswap pull

Pulls the branch the checkout is on and restarts the servers if anything came in, like clawswap pull.

Several projects

Each key has a Watcher setting, empty for http://127.0.0.1:8790. Point keys at another project's port to drive several projects from one deck; keys on the same watcher share its list.

The Elgato app

The plugin speaks the Stream Deck SDK 2 protocol and its manifest also lists macOS, so it may run in Elgato's Stream Deck app too. OpenDeck on Linux is what it's built for; the Elgato app hasn't been tried.
