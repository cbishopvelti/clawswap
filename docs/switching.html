Switching branches

What happens when you press a key, pick a branch on the page, or run clawswap switch.

What a switch does

  1. Refuses if tracked files have uncommitted changes. Commit or stash them first. (Untracked files only stop it if the checkout would overwrite them, and git says so then.)
  2. Replaces each server's pane with a "Switching..." note, which ends the server, and makes sure its port is free.
  3. Checks the branch out: a new local branch tracking origin's, or a fast-forward of an existing one. A branch that has diverged from origin's fails here.
  4. Runs the steps whose when matches a file that changed, in the config's order.
  5. Starts the servers again, even after a failed step, so you're never left without them.
  6. Says the config's notes for what changed.

The clawswap pane shows the output; the page and keys show the step it's on. If the switch changed the config (or a restart_when path), the watcher restarts itself to load the new one.

Pull

A pull is a switch to the same branch: fast-forward, the steps it needs, servers restarted. When there's nothing new it does nothing and leaves the servers running. The page's Pull button, a clawswap pull key and clawswap pull all do it, and each shows how many commits the checkout is behind.

After a manual checkout or pull

If you move the checkout yourself with git, run clawswap update: it runs the steps for what changed since they last ran. clawswap up does the same before it starts a new session.

Which branches are listed

  • The base branch always comes first.
  • With a GitHub token, the branches with an open pull request follow, newest commit first, labelled by PR title.
  • Without one, every branch on origin follows, newest commit first, by its short name.
  • The branch you're on is always listed.

The watcher fetches from origin when the webhook says something changed, every 15 minutes, and when you press a key. Webhook deliveries are only a hint to look again; the watcher never acts on their contents, since anyone with the channel URL could post to it.
