Keys on "next branch" share their watcher's list in deck order, row by row: the first shows the base branch, the rest the newest open pull requests. Pressing one stops the servers, checks the branch out, runs the steps it needs and starts them again.

Watcher is the project's port from its clawswap.config.mjs; leave it empty for the default. Needs clawswap up running in that project.
